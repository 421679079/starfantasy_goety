# 诡厄巫法：星翼幻想

`Goety:StarFantasy` 是星翼幻想系列的 Minecraft 1.20.1 Forge Goety 扩展模组。

## 主要内容

- 为各头衔使徒提供不同的萌化模型。
- 下界使徒添加了对应神环的掉落，添加不同头衔使徒的定向召唤配方。
- 找到冥界教堂，挑战最终 BOSS 亚小妹。
- 添加更强大的魔杖。
- 新增格挡聚晶，施法期间可格挡来自正面的大部分伤害。
- 冥界教堂新增永恒重生锚、战利品宝箱，以及可选的传送石兼容。
- 与亚小妹战斗时死亡保留物品，并优化部分战斗表现。
- 为使徒神环新增更多效果。

当前源码版本：**0.6.1**。
