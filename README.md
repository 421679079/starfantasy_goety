# 诡厄巫法：星翼幻想

`Goety:StarFantasy` 是星翼幻想系列的 Minecraft 1.20.1 Forge Goety 扩展模组。

## 主要内容

- 为各头衔使徒提供不同的萌化模型。
- 下界使徒添加了对应神环的掉落，添加不同头衔使徒的定向召唤配方。
- 找到冥界教堂，挑战最终 BOSS 亚小妹。
- 添加更强大的魔杖。
