# 诡厄巫法：星翼幻想

`Goety:StarFantasy` 是星翼幻想系列的 Minecraft 1.20.1 Forge Goety 扩展模组。

当前公开源码版本：**0.9.1**，运行需要 **Star Fantasy Library 0.2.29 或更高版本**。

## 主要内容

- 为各头衔使徒提供不同的萌化模型、神环掉落与定向召唤配方。
- 探索新结构，挑战全新的BOSS。
- 扩展魔杖、聚晶和仆从。
